# Observation 11 — There is no room on a world for who decided it either

Phase 6 terminated the arrangement into a process that shares no memory with it, and the first thing
that came back was a modelling fact rather than a comparison.

## The answer will not travel on the thing a reader reads

A `Reading` is per world. An attribution is per decision. And Phase 5 measured that one world can be
produced by two decisions.

```text
planner  decided  { staffing }
steward  decided  { staffing, equipping }        ← the same world, claimed by both
```

So there is no field on a world that could hold the answer, and adding one would have had to choose
which claim to keep. This is provenance's finding arriving at the same place from a different
direction — *there is no room on a world for where it came from* — and for the same underlying reason:
identity is derived from content, and a party is not content.

Which means the addressing gain lives on the **decision** and is reached by a query, not by a field.
The fresh process therefore answers a third question:

```text
ape-cli <repository> <instance> <date>                the worlds
ape-cli <repository> transfer <base> <source> <target>  the report
ape-cli <repository> decided <party>                    whose a line is
```

Identities rather than readings, deliberately. An identity is what a transfer is asked about, so what
a party needs in order to be *referred to* is a name that can be handed back — and everything else
about those worlds was already answerable.

## Through the boundary, against literals

```text
three worlds       the shared ancestor and one line per party
decided planner    { staffing }
decided steward    { equipping }
no repository      refused
```

One literal was written wrongly and is corrected against the run: the order the worlds come back in is
not the order the parties wrote in. The planner converged first and its world is second. That is Phase
4's measurement holding from outside — the order is derived from what the decisions carry, so it
cannot be read as arrival — and it is worth recording that the wrong prediction was the intuitive one.

## What the query cannot say

The genesis names nobody, because the field had to be optional. So:

```text
every world           3
claimed by somebody   2
                      1 belongs to nobody, and no query says so
```

A reader cannot tell **not this party's** from **unclaimed**. Making an unattributed decision answer
for whoever is being asked about produces exactly that confusion, which is how this was measured
rather than argued: the genesis appears in both parties' answers and the difference disappears.

That is the honest price of a field four concluded experiments made optional, and it is not a defect
of the query. A query cannot report a distinction the record does not draw.

## And the duplication surfaces here too

The reading form walks decisions, so a world two decisions produced is read twice:

```text
four decisions  →  four readings  →  three distinct worlds
```

Which is the cost Phase 5 measured, seen from where a consumer stands. A reader asking *what worlds
are there* gets an answer with a repetition in it, and the repetition means *two parties agree* — but
only a reader who already knows that a decider exists can read it that way.
