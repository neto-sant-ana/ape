# Observation 5 — A question nobody acted on is not part of the record

Phase 4 asked the corroboration experiment's two questions of every datum, and the only new
candidate was the report itself. It is not written.

## Why not, in the form the rule demands

> *What becomes impossible if this is not preserved?*

Nothing. A report is a function of three worlds and canonical knowledge. The journal produces the
knowledge, the decisions produce the worlds, and asking again produces the report — which is what
the Synthesis layer says about it: not an entity, not stored, obtained again by asking again.

> *What compares it, on every read?*

Nothing that is not already comparing something else. Every input to a report is witnessed:
canonical knowledge by replay, and each of the three worlds by its record in `worlds.json`. A
stored report could only disagree if one of those had already disagreed, and each of those
disagreements is caught first and named more precisely — by position and by coordinate, rather
than by "the answer came back different".

So a report copy would re-detect what the world records detect, and nothing else. That is exactly
the liability the replacement rule names: written, and compared by nothing new.

## What is not derivable, and why it is still absent

Which three worlds were asked about. That is a choice — Synthesis verifies a Base and never
searches for one, so *measured against which world* is part of the question rather than a fact
about the repository.

And this repository holds no transfer to have chosen it for. Phase 3 asked; asking is not
deciding. An application that runs a query and does not act on it has produced no intention, and
this record keeps intentions.

The evidence is sharper than the argument. A recorded transfer would have to name the two worlds
it moves between, and those are the only two in this lineage that nothing extends:

```text
journal.json + lineage.json     the two tips appear nowhere
worlds.json                     both appear
```

Absent from the files that hold intention, present in the file that witnesses outcome. The
pairing is deliberate: an audit that proves nothing is missing by reading the wrong bytes is
worth less than no audit, and this one says where the absence is rather than only that it is.

## What Phase 4 did not decide

Whether a transfer that is **taken** must record its Base. That is Phase 7's, and answering it
here would be answering it before there is a transfer to answer about. The two readings both
remain live:

- a transfer applied is an ordinary fork, and a fork records what it introduced — in which case
  the Base was scaffolding for a decision that stands without it;
- or a transfer applied is a decision *of a different kind*, whose meaning is "the Source's
  intention, measured from the Base" — in which case dropping the Base loses what the decision
  was.

The difference is not cosmetic. Under the first reading the record cannot say why those
commitments were introduced; under the second it can, and pays for it with a coordinate that
must be corroborated like every other.

## The audit, unchanged in kind

The forbidden list this phase inherits grew by one group — every coordinate of a report — and the
closed field set of a decision now covers six decisions across three shapes. Neither is new
machinery. What the phase added is a negative answer with its reasoning attached, which is the
only kind of negative answer worth keeping.
