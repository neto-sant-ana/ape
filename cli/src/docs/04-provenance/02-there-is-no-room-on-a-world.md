# Observation 2 — There is no room on a world for where it came from

Phase 2 asked the repository every question a reader might have about the adopted world. Four have
answers, and the fifth turns out to be a question about a different thing entirely.

```text
what does this world select                    derived      ✓ answered
what did the decision ask for                  recorded     ✓ answered
which world did it extend                      recorded     ✓ answered
when was it taken                              recorded     ✓ answered
which line the intention came from             —            not answerable, and see below
```

## Two measurements, and neither is about what is written down

**A transfer carried and an independent decision are one record.** Byte for byte:

```json
{"decides":"fork","extends":"291e3f84…","omitted":[],"introduced":["b3387f9a…"]}
```

That is what `transfer::applied` produced from the report, and it is also what a planner who never
consulted anybody would write. A transfer applied is not a kind of decision. It is a decision that
happens to have been chosen with a report in hand, and the report is not part of it.

**And the world is the same world.** Deciding the same fork with no transfer behind it produces a
Thesis with the identical identity, because identity is derived from content and two routes to one
content are not two things.

So the fifth question is not unanswered because the record is thin. It is unanswered because
**there is nowhere on a world for the answer to live.** A world is its content; where it came from
is not content.

## The relation runs one way, and that is the whole of the design space

The converse is false, and Phase 2 measured that too. A record can say *more* than a world can
hold: introducing the expansion the receiving line already holds is a request that changes nothing,
so a different intention lands on the same selection and produces the same world.

```text
introduced { tooling }              ┐
introduced { tooling, expansion }   ┴──▶  one world
```

Two records, one world. So if provenance exists anywhere, it is an **annotation on a decision** —
never a property of the thing the decision produced. That constrains Part B before it starts, and
it explains the pressure point the protocol named: a world record disagrees because the world can
be rebuilt, and a provenance claim would be about something no rebuild reaches.

## The standing consequence dissolves, measured

Phase 1 offered one candidate reason to care: of the two plans that explain the adopted world, one
is refused by the account at −5 and the other is not. Did this world take its intention from a plan
that does not work?

The three commitments that make the broad plan infeasible are a **subset** of what the adopted
world selects, and the adopted world is feasible.

```text
broad     { funding, tooling, expansion }              −5   refused
adopting  { funding, tooling, expansion, grant }        20   not refused
```

Which says what infeasibility is: a property of a **selection**, not of a member of one. Nothing
about the refused plan can travel with a commitment out of it, because the commitment never carried
it — the grant the receiving line holds is what makes the same three affordable.

So the candidate consequence is not merely unproven. It is refuted for this arrangement, and the
reason generalizes: what a transfer moves is a set of canonical commitment identities, and an
identity carries no origin and no verdict.

## Where that leaves necessity

Every question about the adopted world is answered without provenance, and the one question that
is not answered has no consequence for the world. What is left of it is a fact about
**deliberation** — who was consulted, and when — which is a statement about the relation between
two lines rather than about anything either line produced.

That is a real thing to want, and it is outside this experiment's boundary: it has no consumer
here, because this boundary has one writer, no agents of decision, and nothing that coordinates.
The protocol excluded exactly that.

Phase 3 remains, and it is the last chance for necessity: it asks what a reader can say about the
worlds that took intention out of a lineage that is later discredited. If the answer is "the same
thing they could say before", the necessity half is refuted and the experiment says so.
