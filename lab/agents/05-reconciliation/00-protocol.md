# Experiment 05 — Two records that diverged

## What this experiment does

Two parties took the same world away, worked without each other, and came back. Their journals
disagree at the first entry after the base, so the application refuses to merge them.

An agent acting for one party is handed both records and asked to end up with one.

> *Does an agent handed a larger boundary use more of it — and does it find, unaided, an operation
> the application does not offer?*

The first clause is the row's own criterion for when a re-run is worth paying for. Its debt page has
said since 26/08/2026 that the three unpaid caveats are **not** the instrument worth building, and that
this is:

> *The migration measured that every assertion keeps its value — which says the substrate preserves
> what the harness asks. It says nothing about whether an agent handed a **larger** boundary uses more
> of it.*

The second clause is why this experiment goes now rather than later, and it is borrowed from the other
row. [`frontier/docs/MERGING.md`](../../frontier/docs/MERGING.md) closed the frontier row's oldest
question and left one thing open in as many words:

> *Whether the application should offer the composition at all, which is a question about convenience,
> and this laboratory has no way to measure that.*

**An agent is that instrument.** A frontier experiment can measure that a composition is *possible*
from the public surface — experiment 15 did, by rebuilding it inside its own test file. It cannot
measure whether a caller who was not told finds it. Nothing in that row has a caller that was not told.

---

## What it is not

**Not a re-run of 01 to 03.** Those measure what the earlier boundaries could carry, and their caveats
are settled by an agent handed the repository doing the same task again. This is a different task on
the boundary as it now stands, which is why it pays no part of that debt and says so.

**Not a test of whether the agent merges correctly.** There is no correct merge to grade against. What
is measured is what it reached for, what it found, and what it said it could not say.

**Not a measurement of `converge`.** The frontier row measured what that operation does and does not
do, across seven experiments. Here it is a **fact of the world the agent meets**, and what is measured
is what the agent does when it meets it.

## What the earlier experiments established, and is not measured again

* **The engine withholds until the caller names something**, and three runs met silences that were
  controls — 01, 02, 03.
* **A handoff was taken**, and what made it safe is that the question stayed askable of the record —
  04.
* **A party is a participant, fully; a party's agency is nowhere** — 04.
* **What ordered everything was the instant each party recorded at, not who they were** — 04. This
  experiment's world is built so that instants are again the thing that decides, without saying so.
* **Two parties in sequence are one line.** 04's arrangement removed the phenomenon it wanted; the
  parties here read the base before either wrote, which is 04's own correction applied.

---

## The world, and why it is this one

**Extended from the world the first four experiments used, not rebuilt.** The house, the account, the
opening of 100, the standing arrangement of 20, `operations` and `finance`. A world chosen to suit this
question would make the finding a property of the arrangement.

```text
base           opening +100 settled, standing −20 intended, one world at the 6th
               claims nobody, because it stood before either party thought anything

operations     took the base away, admitted what it learned, and decided
finance        did the same, without seeing any of it

               → the two journals agree for the whole base and disagree at the entry after it
```

Both parties read the base **before either wrote**, which is what makes them two lines rather than one.
Neither knows the other exists until the agent is handed both.

## Isolation, and what it cannot be here

**The agent is a subagent**, invoked by the operator through the harness this session runs in. That is
the operator's decision about how the session is produced, which the method leaves to them; what the
method requires is that it be reproducible from the record.

**It is a weaker isolation than every earlier run had, and the difference is one thing.** A separate
session begins in the briefing directory. A subagent begins in the repository, so `ls` reaches this
file. The briefing is still assembled to point nowhere — both crates copied in, no path inside the
repository named anywhere in it — but *isolation by construction* is not available and the honest claim
is smaller:

> The agent was never handed a route to this directory, was instructed to work only in the briefing,
> and **could have looked**. Every earlier run could also have looked; this one starts closer.

**And the vendored crates had eight routes in, which is new and is this session's doing.** Since
experiment 04 the application's docstrings began citing the laboratory by path —
`lab/frontier/docs/15-assimilation`, `lab/agents/04-multiagent`, and six more. Every one is removed in
the vendored copy and every edit is recorded with its digest, the way 04 recorded its one edit. What is
kept is the prose those paths sat in: a library that says why it is shaped as it is is what a legitimate
caller has, and the section below measures exactly how much that comes to.

**The route is closed rather than avoided, and that is new.** `lab/` is made unreadable by the
filesystem for the duration of the run — measured, as a non-root user, against `cat`, `ls` and a
recursive `grep` from above. The run record has the commands and the alternatives that were rejected;
what matters here is that every earlier run's isolation was an arrangement and this one's is a
permission bit.

Three things narrow what is left, and none closes it:

* **The agent is asked to list every path it read**, as part of its deliverable. Self-reported, like
  *what it reached for and did not find* already is.
* **`MERGING.md` is the file that would ruin this run**, and it is named here so that a reader knows
  exactly which leak to check for. It holds the answer to the second clause of the question.

If the run's report shows it read anything under `lab/`, the run is **void** and recorded as void. That
is the one outcome this protocol fixes in advance, because the temptation afterwards would be to weigh
how much it saw.

## What the library tells the agent, measured before the frictions are written

**This section exists because the first draft of the frictions predicted things the briefing answers.**
A friction the briefing names is a friction the briefing caused, and four of five predictions were that
shape before this was read. The boundary grew in **documentation** as much as in code, and a protocol
that did not measure the documentation would have graded the agent on its reading comprehension.

Read out of the vendored crates, verbatim in substance:

```text
the two are divergent      `Diverged`'s own MESSAGE says it — "the two hold N entries in
rather than incompatible   common, so they are divergent rather than incompatible". Not a
                           discovery. A sentence handed over

the recovery, and its      `converge.rs`: read again and admit again, and the party whose
order                      knowledge is dated earlier has to land first, because a Canon
                           refuses an admission dated before its watermark

what `by` means            `lineage.rs`: the party that TOOK the decision, and what it does
                           not check is the attribution

that a custody claim       `repository.rs`: what it is, why the write derives it, and what

```

What the crates **do not** say, anywhere:

```text
that the other party's decisions can be RETAKEN in this record's frame — a new decision
carrying the same intention, with this record's coordinate, witness and instant. That is
experiment 15's finding and it lives in the laboratory, which is not in the briefing.
```

So the experiment is not *does it discover the boundary*. It is:

> **The boundary documents itself. Does the documentation carry — and is the one thing it does not
> document the one thing that does not happen?**

## Pre-registered frictions

Five, written after the section above and against it.

**F1 — everything the library states, the agent uses.**

*Prediction:* the four rows above all show up in the run — it reads the refusal as divergence rather
than incompatibility, lands the earlier-dated material first, does not mistake `by` for authorship, and
knows a fourth file exists.

*This is deliberately the easy one*, and it is here as the **control**. If documented facts do not
carry, nothing else in this experiment can be read, and the finding is about the documentation rather
than about the agent.

**F2 — the one thing not documented is the one thing that does not happen.**

*Prediction:* **it does not retake the other party's decisions.** It learns their entries, and stops
at their intentions — because learning has an obvious shape and retaking does not, and nothing it can
read says a retaken world is never the world the other record decided.

*Refuted if* it retakes them in its own frame, which answers
[`MERGING.md`](../../frontier/docs/MERGING.md)'s open question **yes**: the composition is findable by a
caller who was not told, and a laboratory that declined to build it on the grounds that it is
*composable from the public surface* was right.

**F1 with F2 is the experiment**, and they are a pair rather than two items: F1 establishes that the
documented carries, so that F2's silence is about the undocumented rather than about the reader.

**F3 — it ends with a record that is not admissible, or it ends with nothing.**

*Prediction:* one of the two, rather than a clean partial. The order the instants force is real, and a
caller that gets it wrong is refused by the Canon rather than allowed to write something crooked.

*Refuted if* it produces an admissible record holding both parties' knowledge — which would be the
learning half of the composition, done right, without the deciding half.

**F4 — it reaches for a way to say where the other party's material came from.**

*Prediction:* it reaches, and says it could not. Experiment 17 measured that `by` is the wrong field and
that the record has no second relation; three agents in earlier runs reached for something adjacent.
`lineage.rs` tells it what `by` means, so what is measured is whether it wants the thing that is
**not** there.

*Refuted if* it does not reach at all, which would say 17 measured a want nobody has.

**F5 — it never opens `custody.json`.**

*Prediction:* it does not, even though `repository.rs` describes it, because nothing in the task needs
it. Pre-registered because *a larger boundary* has to be falsifiable in both directions: a boundary the
agent is told about and does not touch is a boundary that grew for reasons this task cannot see, and
saying so is the honest half of the first clause.

## Procedure

### Phase 0 — The world, and the two records

Built by the harness and written to the briefing, with every digest published before the agent exists.
The two records are read once here and the refusal they produce is recorded as a literal, so that what
the agent meets is what this protocol says it meets.

### Phase 1 — Brief

`GOAL.md`, both crates, both repositories, an empty `src/main.rs`. Built and compiled before the agent
is invoked, which is the first run's mistake turned into a step.

### Phase 2 — Invoke

One subagent, one prompt, naming the briefing directory and nothing else.

### Phase 3 — Record what came back

Its program, its `ANSWER.md`, its output, and the state it left the repositories in — as written, before
any of it is judged.

### Phase 4 — Judge against the five frictions

Each answered from what the run produced rather than from what it could have produced.

### Phase 5 — What it asked for and did not find

The row's most informative signal, and the one thing every earlier run has contributed to.

---

## Success criteria

1. The briefing is self-contained, its digests are published before the agent is invoked, and they are
   re-checked afterwards.
2. The agent's report lists what it read, and nothing under `lab/` is in it.
3. All five frictions are answered, including the ones answered *no*.
4. What the agent could not say is recorded in its own words.
5. Nothing is added to the APE engine, and nothing to the application.
6. The run is recorded before it is judged.
7. Where a finding contradicts an earlier result, it is recorded as this experiment's rather than
   folded into that one.

**Criteria 2 and 3 are the experiment.**

---

## Failure conditions

The severe one, and it is procedural:

> If the agent read anything under `lab/`, the run is **void**. Not weighed, not discounted — void, and
> recorded as void, because the alternative is an argument about how much it saw.

And the ordinary ones:

* a briefing assembled from an earlier one, which has already cost this row a near miss;
* the agent handed the frontier row's answer by a path nobody meant to include;
* *it did not use the new surface* reported where what happened is *the task did not need it*;
* a friction graded generously because the run was interesting.

---

## Excluded

* **The re-run debt.** Not paid here, and this experiment is not an argument that it should not be.
* **A second agent.** One party, one session. Two is the next question and it is not this.
* **Whether the merge is right.** There is no key.
* **The engine.** As always.

---

## The thesis this bears on

Four experiments agree that coordination never needed to know who decided, only under what knowledge —
indifference rather than integration, and it is not passive.

This asks the first question the row has asked about the *application* rather than the ontology: the
frontier row spent seven experiments establishing what two records can and cannot do, and wrote down
that whether the last piece should be offered is a question it has no instrument for.

If an agent finds the composition, the answer is that the record already carries it and a caller can
reach it. If it does not, then a capability that is provably available and reliably unfound is not a
capability, and that is a sentence about every *composable from the public surface* this laboratory has
used to decline building something.
