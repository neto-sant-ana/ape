# Observation 2 — A party resolves, a world does not, and resolving is not checking

**P1 and P2 confirmed**, and the pair is the whole of what the record can *find*.

```text
                              before the crossing    after it
  a party of the base              resolves          resolves
  the source's party           does not resolve      resolves
  the source's world           does not resolve      does not resolve
```

The first row is the control, and it is criterion 2 of this experiment. `merchant` is a party both
records always held; `analyst` is admitted by no base. Without the first row the phase would be
measuring the shared vocabulary and reporting it as learning.

**A world is produced and never admitted**, so it is in no journal and reaches no archive but the one
that built it. `extends` is the record's only way of naming a world, and putting the source's identity
there is refused by name:

```text
ExtendsUnknownWorld { thesis: <the source's first world> }
```

with the control beside it — a world this record *did* produce extends without complaint, so the
refusal is about the world named and not about the operation.

## And it resolves in a record that took no intention at all

The measurement that separates *resolves* from *checks*, reached from the side nobody looks at.

A record shown the other's whole record, which learned all four entries and **declined every one of
its intentions**, resolves `analyst` exactly as well as the record that took them all.

> So a party's name resolving is a fact about the **journal**. It says that this record holds an agent
> by that identity. It says nothing about an intention having crossed, nothing about which record the
> intention came from, and nothing about the sentence a relation naming it would make.

The two words are one letter apart in a sentence and a world apart in what they buy, and this is where
the experiment could most easily have reported the first while meaning the second.
