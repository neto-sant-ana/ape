# Observation 2 — A file that can refuse, and cannot remember

B is built, and C is measured against it. Ten guards, and the shape holds on the one thing A could
not do and fails on three others — two of which nothing predicted.

## What was built, and where

The bare pointer, in the laboratory: `designation.json` beside the four files, holding one
`ThesisId`, checked against `worlds.json` on read. Three states rather than two.

```text
NoClaim         no file — a record making no claim, which is custody's tolerance
Names(w)        a world this record holds
Unresolved(w)   a claim the record refuses, with the identity in the refusal
```

It is in `tests/designation.rs` rather than in `cli/`, and the docstring says why: the row's rules
say an experiment may not change the application, and the protocol says *B, built*. Both hold by
building it where the phases that measure it live. Whether any of it earns its way into `ape-cli` is
a separate reviewed act, after this experiment concludes.

**Bare on purpose.** P5 asks whether a pointer can answer *what was the plan on the twelfth*.
Building the answer into the shape before the phase asks would have made the phase a formality.

## P2 — the check works, and the lifecycle does not

**The comparison A could not make, B makes.** The same claim that Phase 1 aimed at sixty-four zeroes
— admitted, written whole, read back, unremarked — is refused here, by name, with the identity in the
refusal.

```text
Phase 1   journal    a world that does not exist   admitted, and read back
Phase 2   fifth file a world that does not exist   REFUSED, and named
```

That is the whole of what moving one layer over buys, and it is the protocol's fourth failure
condition closed rather than produced.

**And the check is weaker than custody's, by construction rather than by omission.** `custody.json`
is a function of the journal, so a replay is a *second derivation of one fact* and the two can
disagree. Nothing derives a plan. The only thing `worlds.json` can contradict is *that the world is
one of this record's own* — existence, and not agreement. Recorded because P2 said *the check is
custody's, one layer over*, and it is the shape that transfers, not the strength.

**The lifecycle does not transfer at all, and this is the phase's concrete finding.** Custody is
derived **by** the write, so it rides inside the all-or-nothing that puts four files in the
generation nothing is reading yet. A designation is supplied. A file written beside the live
generation is a file the next turn leaves behind — the pointer moves to the other generation, which
never had it.

```text
found → designate → admit anything → write whole → plan_of == NoClaim
```

Measured, and the silence is the bad part: a record that *lost* its plan is indistinguishable from
one that never claimed anything. So whatever carries a designation has to be an **input to the
write** — `RepositoryInput` grows a field. That is what this phase hands over.

**What B costs where A was expensive.** Three moves, and the journal holds eighteen entries
throughout, four worlds throughout. Against Phase 1, where the same three moves left three entries
the record could only count as two.

## P3 — one designation cannot hold two parties, and `by` does not help

The record already answers *who decided what*: `Taken::by` names the planner on two forks and the
steward on one. Asked whose **plan** the single designation is, nothing answers. The two facts do not
compose into the third — the steward decided this world and the planner decided two others, and
nothing says the planner is or is not content with the steward's.

**And the genesis claims nobody**, which is why a per-party file is not simply a wider table.

```text
4 worlds     3 claimed by a party     1 claimed by nobody
```

The shared ancestor is everyone's and no one's. A per-party file has no row for it, so *what is the
plan for a reader who is not a party* is a question C has to answer separately rather than inherit.
The arrangement holds that decision deliberately, so the case is present rather than hypothetical.

## P4 — confirmed, and vacuously, which is not the same as confirmed

The merge does not refuse two records that disagree about which world is principal. It refuses
nothing, because **it never sees them**.

Two designations written to one record: the second overwrites the first, in place, with no
comparison anywhere. A refusal would at least have been a fact.

And `converge` — which reads, appends, re-orders, rebuilds and writes whole — is about the four
files throughout. After a merge the knowledge is merged and the record makes **no claim at all**.

```text
journal after the merge   19 entries   the knowledge merged, which is what converge is for
plan after the merge      NoClaim      not refused, not arbitrated, absent
```

P4's prediction rested on *a designation is not knowledge, and disagreement about a plan is
deliberation*. The reasoning survives; the confirmation does not carry it, because nothing weighed
anything.

## P5 — confirmed, and the sharp form is an identity

Two records. One whose plan went `W₁ → W₂ → W₁`; one that designated `W₁` and never moved. Every
file compared, byte for byte — with both sides required to be **present** before they are required
to agree, because two absent files compare equal and that is how this family of guard goes green
measuring nothing.

They are the same record. All five files.

P5 asked whether the answer is derivable from the lineage, and it is not: designating is not
deciding, so the lineage of the two is the same lineage. This is the shape `17-imputation` ended on
— an author and a relay were one record there; a plan that moved and one that never did are one
record here.

The weakest form, so the answer is not mistaken for one about granularity: **the record does not date
the moves badly, it holds no move.** Nothing counts them, and the file holds exactly one identity.

## Where the three homes stand

```text
A  a journal entry   OUT, twice over: not refused, and cannot hold the return
B  a fifth file      the check works and is weaker than custody's; the lifecycle
                     does not transfer; and a bare pointer forgets
C  per party         not measurable against a file that holds one value, and the
                     genesis is a row it has no place for
```

The two failures that matter are the same failure. B forgets what the plan was, and B cannot say
whose plan it is — **and a sequence of designations that each carry a party answers both.** That is
one shape, not two, which is P3's *B and C are the same answer* arriving from a direction the
prediction did not take: not because a designation is per-party, but because whatever fixes the
history is the thing that has room for the party.

Whether that shape is a pointer or a log is now answered. It is a log.
