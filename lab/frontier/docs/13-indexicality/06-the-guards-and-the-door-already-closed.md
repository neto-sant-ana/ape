Derived from the table rather than asserted beside it: **exactly one state answers a number the

legitimate record of a legitimate reading, written by nobody in error.

Two rows are worth reading as results in their own right. *The journal reordered* passes everything
and answers correctly, which is right and is the record accepting a sequence it has no business
minding. *The instant moved within the cut* also passes everything and answers correctly, and is the
state Observation 5 measured: a record can say a fact was learned on a day it was not, as long as no
world moved.

**Seen red at the guard rather than at the subject.** Making `corroborate` never refuse an unwitnessed
entry moves two rows of this table and three cells of Observation 5's, and reports
`("an entry out of the witness", Nothing, Some(400))` where `Witness, None` was written down.

## The misleading state is a repository nobody can write

Which is the whole of the Part B question, and the answer arrived from a guard this row already built.

The application has exactly one operation that takes another record's journal, and it refuses this
one by name:

```text
converge, the record against the sibling      RecordedDifferently
```

That is experiment 11's Part B — one comparison in `appended`, added because a merge that kept the
converging party's instants would re-derive a world its decider had already settled. It was built for
a **merge**. What this experiment measures is that it is also the only thing standing between a
travelling decision and a receiver that would resolve it wrongly, and that nothing else in the
application accepts a decision from elsewhere at all.

So the present shape does not admit the misleading state through any operation it offers. It admits it
as a **file somebody could write**, and the row has ruled repeatedly that a state reachable only by
editing the files is not the same as one an operation produces.

## And the guard is sound rather than complete

```text
converge, the record against the same journal reordered      Diverged { position: 0 }
```

The merge refuses two journals that hold the same knowledge in a different order — the same
reordering the record's own reader was measured above to accept, correctly. `appended` compares two
sequences position by position, and a sequence is not what either journal means.

The same shape experiment 12 measured for the witness: sufficient and not necessary. Recorded as a
request in Observation 7 rather than as a defect, because a refusal that costs an attempt and no
decision is the cheap side of the trade, and nothing measured here needs it to be tighter.

## What this says about where the boundary is

Four results asked for a portable coordinate. The measurement is that the record's answer to a
decision arriving from elsewhere is **refuse**, not **believe** — and that the refusal is correct,
because believing would mean believing an instant nothing derives.

That is authenticity's boundary reached from inside the record, which I4 predicted. It is not the
question *how do I trust a stranger's claim*. It is narrower and more useful: the only claim in a
travelling decision that cannot be settled by holding the content is **when each entry was learned**,
and a key would be the answer to that one value rather than to portability in general.
