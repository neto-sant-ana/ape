# Observation 2 — What escapes the pin, over the whole space rather than over one Event

I2 predicted that what escapes the witness is what no identity carries. Measured, and measured
two-sided, because *the instant escapes* is a claim about an address that would be satisfied by an
address which never moves at all.

Every kind of entry a journal can hold is in the base journal, all nine of them. For each, the phase
takes the prefix ending at it and reads the address that prefix produces, twice:

```text
                       instant moved to day 28    one other field moved
  role                      address held             address moved
  agent                     address held             address moved
  resource                  address held             address moved
  eligibility               address held             address moved
  resource-instance         address held             address moved
  action                    address held             address moved
  statement                 address held             address moved
  commitment                address held             address moved
  event                     address held             address moved
```

Nine for nine, both sides. **The recording instant is the one field of an entry that no address
covers, and it is the only one.** The space searched is the whole enum, which is what makes the
negative reportable: this is not *we did not find another*, it is *there is no other kind of entry*.

The altered field is derived from the entry at that position rather than listed beside it, so a
journal whose shape moved would fail to build the case instead of quietly measuring a different one.

## Order escapes too, and nothing moves with it

A witness is a set, so two admissible sequences of one membership satisfy it alike. Measured:

```text
early and reordered-early    address sequences differ
                             address memberships are equal
                             the knowledge the coordinate selects is one body
                             the answer is the same
```

Recorded as a **measured negative**, and it is the reason I2 is stated separately from I1. What
escapes the present pin is not one thing; it is two, and only one of them is a difference. A phase
that measured only the instant would have reported *the pin omits exactly what matters*, which is a
stronger claim than the arrangement supports.

## Where this stops being experiment 11's result

11 measured that no identity carries a recording instant, and the conclusion it drew was about two
**journals**: they can be equal entry for entry and not be the same journal. That sentence is carried
forward and is not available here.

What is new is the direction. 11 asked what a merge can fail to notice. This asks what a reference
would have to say, and gets the same value back from the other side: the one thing a decision must
add in order to fix the knowledge it names is the one thing an address was already measured not to
carry. Two questions, one value, and Observation 5 is where that stops being a curiosity.

## Seen red, and the guard was the one that needed it

The mutation that matters here is not to the application — it is to the instrument. Making the
subject's re-dating helper move nothing leaves this phase **green**: both halves read an address, and
an instant that never moved satisfies *the address held* perfectly.

It was caught by another phase, three sections down, which uses the same helper for effect rather
than for comparison. That is luck, not design, so the guard now asserts the instrument before it
reads the address:

```text
role: the instant was moved before the address was read
  left: "2026-01-01"
 right: "2026-01-01"
```

The general shape is worth keeping: **a guard whose two halves both read the same derived value can
be satisfied by a mutation that changed nothing**, and the fix is to assert the mutation, not to add
a third reading.
