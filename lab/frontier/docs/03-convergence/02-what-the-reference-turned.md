# Observation 2 — A reference fires earlier and says less

Adding `extends` changed two results the earlier experiments had published. Neither change was
looked for, and recording them is what the protocol's ninth success criterion asks: the earlier
conclusions stand, or the change is a result of this one.

## The reconstruction experiment's Phase 3 stopped holding

That phase asserted that no derived `Thesis` identity appears in the repository. It was already
narrower than it read — the corroboration experiment had added a whole file of derived world
records, and the assertion only ever looked at the lineage — but within the lineage it held
until now.

It no longer does, and the guard is the thing that said so: the suite went red on exactly that
line, unprompted.

What replaced it is the distinction the change turns on:

```text
the world a decision extends   →  written down, as a reference
the world a decision produced  →  still absent
```

The second is the half the phase was always asking about. A decision records what it asked for
and never what it got, and nothing reads a world back either way — a `Thesis` does not
deserialize, so an identity in a repository is an address and never a value.

The divergence experiment's Phase 4 carried the same assertion over its three worlds, and it
now reads as an exact statement: worlds 0 and 1 appear, because something extends them; world 2
does not, because nothing does.

## The corroboration table is turned by a different witness

Three of the corruptions the corroboration experiment measured now stop being refused by the
witness that experiment credited. Each of them alters the genesis, the advancement names the
world the genesis produced, and the reference stops resolving before anything compares a world.

The verdicts are unchanged — every corruption that was refused is still refused. What changed is
the diagnosis, and it changed for the worse:

```text
WorldDisagrees        world 0 disagrees with what was recorded, in what it still proposes
ExtendsUnknownWorld   the decision extends world 53e2b385…, which the lineage does not hold
```

One names the coordinate that moved. The other names a world that could not be found, which is
a true statement that sends a reader somewhere else to learn anything from it. The reference
wins the race because it is resolved as the rebuild walks, and the world witness is weighed
after the whole lineage exists.

**Two of the three were restored rather than accepted.** The corroboration experiment's Phase 5
*subtracts* a corroborator to see what is left; a subtraction that also leaves a stale reference
behind has introduced a second inconsistency, and the refusal it produces is evidence about that
one. Those corruptions now recompute `extends`, and the world witness says what it always said.

The one left alone is the narrowed intention of Phase 2, and deliberately: that phase is a table
of edits by someone who does not recompute derived values, so a stale reference is in character
for it. Its conclusion needs one qualification, which the harness now carries:

> A reference corroborates every world that something extends. A world nothing extends — the leaf
> of a lineage — is still covered only by the world witness.

In the divergence lineage that leaf is the fork, and narrowing *its* intention would still be
turned by the world record alone. The corroboration finding is narrowed, not overturned.

## The cost of a consistent forgery went up

The corroboration experiment's Phase 7 measured that a forger who edits a repository and
recomputes every derived value passes undetected. That still holds, and it now costs more: the
forgery recomputed the sequence witness, and had to be taught to recompute `extends` as well —
which cannot be read off the file, only re-derived by applying the decisions one at a time.

Making the harness do that work is the measurement. A reference to a derived value is one more
thing a consistent forgery has to be consistent about, and it is the first one in this repository
that a forger cannot produce without running the engine.
